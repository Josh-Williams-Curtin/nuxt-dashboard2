# nuxt-dashboard

Full-stack Nuxt 4 application with Nuxt UI v4. Frontend and backend run on the same server via Nitro.

## Setup

```bash
bun install
```

## Development

```bash
bun run dev
```

## Build & Preview

```bash
bun run build
bun run preview
```

## Lint & Type Check

```bash
bun run lint
bun run typecheck
```
